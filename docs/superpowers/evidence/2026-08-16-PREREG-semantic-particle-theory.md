# PREREGISTRATION — Semantic Particle Theory

**Written 2026-08-16 BEFORE any confirmatory particle experiment is read as
a parser result.** Predictions below are declared, not fitted. The
implementation that landed today is the contract and the observers. It is
not evidence that any theory works.

## Question and causal mechanism

Which minimal semantic annotations can improve selection among already-licensed
readings and derivations without expanding the legal bond set, introducing
nondeterminism, or minting recursive privilege?

Object that changes: a frozen packed chart's *annotation / ranking report*.
Layer: downstream of `admitBond`. Grammar, lifts, and roots stay byte-identical
in annotation and ranking arms.

## Frozen substrate (to be hashed into every report)

- commit
- grammar checksum (active constructions)
- lexicon checksum
- corpus files (EWT DEV / sealed TEST, plus the 395-sentence gate as a
  regression chamber only)
- `SEMANTIC_PARTICLE_SCHEMA_VERSION` and `particleSchemaChecksum()`
- `options.semanticParticles` mode
- `maxTokens` and hardware-independent counters (events, bondAttempts,
  recursive-preservative firings)

The 26-sentence beacon slice is a smoke test, not the confirmatory set.

## Primary endpoints (one per theory)

Declared in the paper, Appendix B. Holm correction across the ten
confirmatory tests. Secondary endpoints are descriptive unless separately
powered.

## Protection endpoints

Coverage, gold containment, head pins, garden-path pins, stable imperative
roots (`Round!`), events mean/p95/max, recursive-preservative firings,
queue/stack parity, packed/classic parity on bounded fixtures, determinism,
zero throws.

A gain elsewhere cannot compensate a protection miss.

## Standing gates (paper Table 4)

1. Two identical runs → byte-identical report hashes and forest fingerprints.
2. BONDS / lifts / roots / active construction IDs unchanged in
   annotation/ranking experiments.
3. No decline in preregistered containment, heads, garden paths, or
   imperative roots.
4. Event / rec-pres ceilings held. Event suppression with spanning loss fails.
5. Real particles beat deranged / shuffled / null controls.
6. Direction and minimum effect hold on sealed TEST (and a second genre
   group before any cross-corpus claim).

## Falsifiers

See paper Table B1. A failed theory stays in the ledger.

## Promotion rule

Observe → score, and score → consume, only after the annotation evidence
beats controls and protection holds. Consume still cannot admit a bond.
Grimoire change is a separate reviewed act.

## Declared prediction

I do not predict a coverage gain. I predict that if anything useful exists
here it will appear as discrimination among already-licensed derivations
(T2 local, T3 global) and as safety observability (T4, T5), and that
diversity-only search (T10) will not raise the quality ceiling.
